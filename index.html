SDR Reference Guide

Subscriber Detail Records (SDR) contain core identity markers collected by network operators when registering new connections.

Primary Fields Tracked:

  • Subscriber Name & Photo
  • Registered billing address
  • Document Type (Passport/DL)
  • Alternate phone ties

Connecting SDR records with raw call metadata (CDR) allows analysts to replace raw digits on graphs and maps with suspect names and profiles automatically.
